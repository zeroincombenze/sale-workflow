Add account on Sale Order Line for invoice

Aggiunge il conto di ricavo per la fatturazione

This module add income account field on Sale Order Line. If the account is set, the value is copied on the invoice. When field is None, income account is set as in Odoo usual way.

Questo modulo aggiunge il conto di ricavo sulla riga ordine. Se compilato, il valore è copiato nella fattura. Se il valore è nullo, il conto di ricavo è impostato con le usuali regole di Odoo.

Usage | Utilizzo

Set account value if you want a specific value for the line.

Impostare il valore del conto che si vuole impostare nella riga.
