On Consignment and For Evaluation Sale management

Gestione dei flussi di conto deposito e conto visione

This module manages On Consignment workflow and For Evaluation workflow. It is based on sale_order_type_plusmodule in order to create specific Sale Order and Return Merchandise Authorization (RMA) for returned goods.

This module manages the transfers thru 2 locations, 'on consignment' and 'for evaluation'. User can always see all product delivered on consignment o for evaluation and knows who holds goods.

Questo modulo gestisce i flussi di conto deposito e conto visione. Il modulo è basato sul modulo sale_order_type_plusper creare specifici tipi di ordine di vendita e creare le RMA per gestire il rientro merce.

Il modulo gestisce i trasferimento attraverso 2 ubicazioni specifiche, di c/lavoro e c/visione. L'utente può quindi sempre visionare i prodotti consegnati in conto visione o conto deposito e conoscere a presso quale cliente è giacente la merce.

Configuration | Configurazione

To configure Sale Order Types you need to:

Sales > Configuration > Sales Orders Types

Create a new sale order type with all the settings you want

Per configurare il modulo.

Vendite > Configurazione > Tipi Ordine di vendita

Impostare la configurazione desiderata dell'ordine di vendita.

Usage | Utilizzo

Sales > Sales Orders > Click on button  Create  > Select the one of 'On Consignment' or 'For Evaluation' order type.

After picking confirmation, all products will be transferred in specific location and assigned to partner.

In order to see inventory:

Inventory > Reporting > Inventory Report > Click on button Retrieve the inventory quantities

In the list view, the product transferred 'on consignment' or 'for evaluation' are displayed with negative sign in internal location line. If you filter the external locations, you can see the 'on consignment' and 'for evaluation' locations. All these product are assigned to a partner.

This module can manage lots and serial numbers too.

Vendite > Ordine di vendita > Fare click sul bottone  Creare  > Selezionare il tipo di ordine 'Conto deposito' oppure 'Conto visione'

Alla conferma del preliveo i prodotti saranno trasferiti nella specifica ubicazione e assegnati al cliente.

Per visionare le giacenze:

Inventario > Rendicontazione > Resoconto di Magazzino > Fare click sul bottone Recupera le quantità di inventario

Nella lista i prodotti in giacenza in conto deposito o conto visione sono visualizzati con valore negativo nell'ubicazione interna di stock. Selezionando anche le ubicazioni esterne è possibile vedere le ubicazioni di 'conto deposito' o 'conto visione'. Tutti i prodotti in conto deposito o conto visione sono assegnati ad un cliente.

Il modulo è compatibile con la gestione dei lotti e numeri di serie.
