S.O. type to manage On Consignment / For Evaluation

Tipi di ordine per gestire conto deposito / conto visione

This module adds some features to Order type:

  • Destination location based on order type
  • Automatic owner assign or deassign on picking confirmation
  • Automatic picking validation upon sale order confirmation

Questo modulo aggiunge alcune caratteristiche aggiuntive al tipo di ordine.

  • Ubicazione di destinazione basata su tipo ordine
  • Assegnazione o deassegnazione automatica del proprietario dello stock
  • Validazione automatica del picking alla conferma ordine

Configuration / Configurazione

To configure Sale Order Types you need to:

Go to: Sales > Configuration > Sales Orders Types Create a new sale order type with all the settings you want

The field 'Picking Auto Confirmation' requires module sale_order_lot_selection.

Per configurare il modulo.

Dal menù: Vendite > Configurazione > Tipi Ordine di vendita impostare la configurazione desiderata dell'ordine di vendita.

Il campo 'Auto conferma prelievo' richiede il modulo sale_order_lot_selection.

Usage / Utilizzo

Go to: Sales > Sales Orders, and create a new sale order. Select the new type you have created before and all settings will be propagated.

Dal menù: Vendite > Ordine di vendita, creare un nuovo ordine. Selezionare il tipo di ordine desiderato e i dati configurati sarano impostati.

Known issues / Problemi conosciuti

This module replaces the standard Odoo function sale.order._action_launch_stock_rule() of the module sale_stock. The function, now can use the destination location different from the partner destination location. In this way is very simple to manage sale order on consignment or for evaluation or for tolling agreement or for subcontracting. For this reason, this module depends on specific 12.0.1.0 version of sale_stock module

This module may conflict with sale_order_automatic_workflow because overlaps some features of that module. Please choice this module or else *sale_order_automatic_workflow* but not both.
