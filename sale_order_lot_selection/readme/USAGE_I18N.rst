Scegliere il lotto / numero di serie tra quelli disponibili nella lista della riga
ordine. Per facilitare la scelta viene visualizzata anche la quantità di ciascun
lotto / numero di serie.
Se si desidera dichiarare più numeri lotti / numeri di serie per lo stesso prodotto è
necessario inseire più righe dello stesso prodotto.
Utilizzando il modulo *sale_order_type_plus* è possibile impostare la conferma
automatica del prelievo alla conferma dell'ordine per lo specifico tipo di ordine.
