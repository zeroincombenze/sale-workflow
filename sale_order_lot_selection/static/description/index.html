Serial Number or Lot selection in Sale Order line

Selezione numero di serie o lotto in riga ordine di vendita

This module add the field lot in Sale Order line view. It is an improvement of OCA module. User can choices serial number or lot in every order line from list of available serial number / lot in stock; user can see available quantity for every serial number / lot.

This value is inherited by picking when sale order is confirmed.

Thru module sale_order_type_plusis possible auto confirm picking upon sale order confirmation.

Questo modulo aggiunge il campo "lotto/numero di serie" nella riga della vista ordine cliente. Derivato da modulo OCA con alcune migliorie. L'utente può scegliere il lotto o il numero seriale dalla lista tra i disponibili in magazzino. L'utente vede, nella lista, anche la quantità disponibile.

Il valore è riportato nel prelievo.

Attraverso il modulo sale_order_type_plusè possibile confermare automaticamente il prelievo alla conferma dell'ordine.

Configuration | Configurazione

To configure lot selection you need to:

Inventory > Configuration > Settings > Enable 'Lots & Serial Numbers'

If you have installed the module sale_order_type_plus

Sales > Configuration > Sales Orders Types > Enable 'Picking Auto Confirmation'.

Per configurare il modulo.

Inventario > Configurazione > Impostazioni > Abilitare 'Lotti e numeri di serie'

Se installato il modulo sale_order_type_plus

Vendite > Configurazione > Tipo ordine di vendita > Abilitare 'Auto conferma prelievo'.

Usage | Utilizzo

Please, choice the serial number / lot from list in sale order line. In order to simplify the choice you can see availabel quantity for every serial number / lot.

If you wish add more serial numer / lot than one, please add a new order line with the same product.

Using module sale_order_type_plusis possible set the auto confirmpicking upon sale confirmation for specific order type.

Scegliere il lotto / numero di serie tra quelli disponibili nella lista della riga ordine. Per facilitare la scelta viene visualizzata anche la quantità di ciascun lotto / numero di serie.

Se si desidera dichiarare più numeri lotto / numeri di serie per lo stesso prodotto è necessario inserire più righe dello stesso prodotto.

Utilizzando il modulo sale_order_type_plusè possibile impostare la conferma automatica del prelievo alla conferma dell'ordine per lo specifico tipo di ordine.
