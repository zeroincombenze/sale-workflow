Serial Number or Lot selection in Sale Order line

Selezione numero di serie o lotto in riga ordine di vendita

This module add the field lot in Sale Order line view. User can choices serial number or lot in every order line from list of available serial number / lot in stock; user can see available quantity of every serial number / lot. This value is inherited by picking when sale order is confirmed (notice: this feature is not available in OCA module). Thru module sale_order_type_plus is possible auto confirm picking upon sale order confirmation.

Questo modulo aggiunge il campo "lotto/numero di serie" nella riga della vista ordine cliente. L'utente può scegliere il lotto o il numero seriale dalla lista dei disponibile in magazzino. L'utente vede anche la quantità disponibile nella lista. Il valore è riportato nel prelievo (notare che questa funzione non è disponibile nel relativo modulo OCA). Attravaerso il modulo sale_order_type_plus è possibile confermare automaticamente il prelievo alla conferma dell'ordine.

Usage / Utilizzo

Please, choice the serial number / lot from list in sale order line. In order to simplify the choice you can see availabel quantity for every serial number / lot. If you wish add more serial numer / lot than one, please add a new order line with the same product. Using module sale_order_type_plus is possible set the auto confirmpicking upon sale confirmation for specific order type.

Scegliere il lotto / numero di serie tra quelli disponibili nella lista della riga ordine. Per facilitare la scelta viene visualizzata anche la quantità di ciascun lotto / numero di serie. Se si desidera dichiarare più numeri lotti / numeri di serie per lo stesso prodotto è necessario inseire più righe dello stesso prodotto. Utilizzando il modulo sale_order_type_plus è possibile impostare la conferma automatica del prelievo alla conferma dell'ordine per lo specifico tipo di ordine.
